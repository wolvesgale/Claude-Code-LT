Insights

この軌跡が教えてくれること

非エンジニアでも、LT参加者全員に刺さるはずのこと。

🚀

「作った」という事実が最強の説得力

ドキュメントより、動くURLを見せる方が100倍早い。Claude Codeなら当日デプロイも現実。

🔧

エンジニアじゃなくても「難しかった」はある

AWS IAM・DynamoDB移行・CORS設定… 壁は全員に来る。ただしClaude Codeと一緒に乗り越えられる。

💡

「できた」は積み重なる

1つ動いたら2つ目は早い。4ヶ月で7プロジェクトはその証明。最初の1本が全てを変える。

🤔

Codex / Antigravity との違いは「対話」

Claude Codeは「なぜ」を説明してくれる。学びながら作れるのが非エンジニアには最強。

🌏

現場の人こそ使うべき

業務の痛みを一番知っているのは現場の人。その知識×Claude Codeで「自分専用ツール」が生まれる。

📈

副業・受託への橋渡し

「作れる」が証明できれば、案件は来る。エンジニア資格は要らない、動くものが全てを語る。

Try it now

その場で試せる、魔法のプロンプト 🪄

Claude Code（またはClaude.ai）を開いて、↓を貼り付けてみてください。
今夜あなたの「第一歩」が始まります。

🌱 ステップ1 ： 最初のLPを作る

あなたの「自己紹介LP」を1つのHTMLファイルで作ります。

Claude Code プロンプト あなたはWebデザイナー兼エンジニアです。 以下の情報を元に、私の自己紹介ランディングページを1ファイルのHTMLで作成してください。 【私の情報】 ・名前（ニックネーム）: [あなたの名前] ・肩書き / 職業: [例: エンジニア、営業、デザイナー etc.] ・得意なこと・好きなこと: [自由に] ・作ったもの・やってみたいこと: [自由に] ・一言メッセージ: [自由に] 【要件】 - ダークテーマ・モダンなデザイン - アニメーションを入れてかっこよく - スマホでも見やすいレスポンシブ - CSSはstyleタグにまとめて1ファイルで完結させること - 絵文字でイラスト的な表現を使ってOK 完成したら index.html として保存してください。

🚀 ステップ2 ： Vercelに公開する

作ったHTMLをインターネットに公開します（無料・3分）。

Claude Code プロンプト 先ほど作った index.html を Vercel で公開したいです。 以下の手順で進めてください。 1. このフォルダを git リポジトリとして初期化（まだなら） 2. GitHub に新しいリポジトリを作成して push する 3. Vercel CLI でデプロイするか、Vercel の Web UI でデプロイする方法を教えてください Vercel は無料プランで大丈夫です。公開後のURLを教えてください。
