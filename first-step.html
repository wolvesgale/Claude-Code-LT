Challenges & Wins

難しかったこと、
こうやって乗り越えた

壁は全員に来る。でも Claude Code と一緒なら越えられる。

🔐

難しかったこと

AWS IAM 権限設定 — エラーが謎すぎて詰まる

→

乗り越え方

エラーをそのままClaude Codeに貼り付け→原因と修正コマンドを教えてくれた

🗄️

難しかったこと

SQLite → DynamoDB 移行 — データ構造が全然違う

→

乗り越え方

「移行計画を立てて」と依頼→設計からマイグレーションスクリプトまで自動生成

🌐

難しかったこと

CORS エラー — フロントとバックが繋がらない

→

乗り越え方

コンソールのエラーをコピペ→1行の設定追加で解決
